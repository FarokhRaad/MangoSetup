# =============================================================================
#  App catalog: candidate apps per role, for scripts/setup.sh's interactive
#  picker.
# =============================================================================
#  Verified 2026-07-30 against pacman -Si (repo) and the AUR RPC (AUR), plus
#  each AUR package's PKGBUILD where the installed binary name differs from
#  the package name (a real trap: e.g. package microsoft-edge-stable-bin
#  installs binary `microsoft-edge-stable`; package sublime-text-4 installs
#  binary `subl`, not `sublime-text-4`).
#
#  Format per line (pipe-separated, no spaces around pipes):
#    role|package|binary|source|label
#  role    : matches a $ROLE in configs/.config/mango/conf/apps.conf
#  package : exact pacman/AUR package name to install
#  binary  : exact command name to check with `command -v` / launch
#  source  : repo | aur
#  label   : human-readable name shown in the picker.
#            Do NOT encode "default" in a label: which app is the active
#            default is defined solely by the env=ROLE,value line in
#            configs/.config/mango/conf/apps.conf (changed via
#            scripts/swap-app.sh), never by this file.
#
#  This file is DATA for scripts/setup.sh, not sourced by mango or bash.
#  Multiple apps per role are expected and supported: the picker is a
#  multi-select (gum choose --no-limit), so e.g. selecting Firefox, Edge,
#  and Brave together installs and registers all three; scripts/apps.conf
#  and scripts/swap-app.sh (single active default via $ROLE) still control
#  which ONE of the installed set mango/exec-once actually launches by
#  default at any given time, per app.conf's own header.
# =============================================================================

# --- Shell ($SHELL) -----------------------------------------------------------
#  bash is already installed on every Arch system (it is in `base`), so it is
#  listed purely so the picker can show it and so choosing it is explicit.
#  The repo ships configs for bash and zsh (.bashrc + .config/bashrc/,
#  .zshrc + .config/zshrc/), so either lands in a configured shell.
#
#  COMPANION PACKAGES: a 6th pipe-separated field, space-separated, installed
#  ONLY when that row is selected. This is why zsh-autosuggestions and
#  zsh-syntax-highlighting are absent from packages.txt: a bash-only machine
#  should not carry them. setup.sh reads field 6 generically, so any future
#  row can use it.
#    role|package|binary|source|label|companions
#
#  Picking a shell here also offers to run `chsh`, since exporting SHELL does
#  not change the login shell recorded in /etc/passwd.
SHELL|bash|bash|repo|bash (already present on Arch)
SHELL|zsh|zsh|repo|zsh (+ autosuggestions & syntax highlighting)|zsh-autosuggestions zsh-syntax-highlighting
SHELL|fish|fish|repo|fish (no repo config shipped - you configure it)
